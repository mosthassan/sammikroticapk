# SamMikrotik - قائمة التحقق من الجاهزية للنشر (Release Hardening Checklist)

## 1. تكوين البناء والإنتاج (Build & Release Configuration)
- [x] **تطبيق المخطط وحفظه:** تم حفظ مخططات Room في `app/schemas` مع تفعيل KSP.
- [x] **ترقية قاعدة البيانات:** كتابة ترحيل معتمد `MIGRATION_1_2` دون أي فقدان للبيانات.
- [x] **حظر الترحيل المدمر:** منع `fallbackToDestructiveMigration` نهائياً.
- [x] **حماية المفاتيح السرية:** اعتماد `Secrets Gradle Plugin` وإدارة المفاتيح عبر `.env`.
- [x] **قواعد التحسين R8/ProGuard:** قواعد مخصصة في `app/proguard-rules.pro` لحماية Room, Moshi, Retrofit, Firebase, Coroutines.

## 2. النواة المحاسبية والامتثال لمعايير IFRS
- [x] **دفتر الأستاذ مصدر الحقيقة:** جميع الأرصدة مشتقة من أسطر القيود.
- [x] **أرقام صحيحة للأموال:** جميع العمليات المالية مبنية على `Long` بوحدات السنت / الفلس (`Money`).
- [x] **مناعة القيود:** مشغلات SQLite تمنع تعديل أو حذف أي سطر قيد مرحل.
- [x] **مسار كتابة أحادي:** جميع المعاملات المالية تمر حصرياً عبر `LedgerWriter`.
- [x] **تحقق مستمر من الثوابت:** فحص ميزان المراجعة وتطابق الذمم والأطراف بعد كل دورة مزامنة.

## 3. الأمان وإدارة الصلاحيات
- [x] **قواعد Firebase Firestore:** ملف `firestore.rules` يحظر تعديل أو حذف القيود ويفرض صلاحيات المنظمات.
- [x] **نظام RBAC الصارم:** منع الكاشير من العمليات المحاسبية الحرجة، وتسجيل الانتهاكات في `audit_log`.
- [x] **قفل التطبيق:** دعم قفل PIN والمصادقة البيومترية.

## 4. الذكاء الاصطناعي المسؤول
- [x] **العزل المحاسبي:** الذكاء الاصطناعي لا يكتب في الأستاذ مطلقاً؛ كل مخرجاته مسودات تتطلب تدخلاً بشرياً صريحاً.
- [x] **مطابقة الأرقام:** استخراج البيانات المالية من أدوات القراءة الرسمية دون أي اختراع للأرقام.
- [x] **العمل دون اتصال:** توفير حلول معالجة محلية بديلة عند غياب الاتصال بـ Gemini API.

## 5. تجربة المستخدم والتوطين
- [x] **العربية أولاً (RTL):** واجهات متناسقة بالكامل تدعم الاتجاه من اليمين لليسار.
- [x] **الأرقام والمبالغ:** استخدام مكونات `AmountText` وأرقام جدولية لتفادي التداخل في القراءة.
- [x] **التجاوب:** دعم مختلف قياسات الشاشات والهواتف والأجهزة اللوحية.
